From 1.0 these formats follow semantic versioning. Breaking changes need a new major version.

| Format | Version | Defined in |
|---|---|---|
| `gitgrounded.yml` | `version: 1` | `src/gitgrounded/config/schema.py`, `gitgrounded schema` |
| case JSONL | v1 | `src/gitgrounded/cases/model.py` |
| run result | `schema_version: "1"` | `src/gitgrounded/report/model.py` |
| evidence bundle | `ggb/1` | `src/gitgrounded/evidence/bundle.py` |
| certificate bundle | `ggb-cert/1` | `src/gitgrounded/evidence/certify.py` |
| attestation predicate | `eval-run/v1` | [Attestation format](/docs/attestation/eval-run/index) |

## Deprecation policy

A deprecated option or command keeps working for one minor release and prints a warning naming its replacement.

The hackathon flags `--old`, `--new`, `--check`, `--compare`, `--labels` and `--del-v` were removed in 0.2 and now print the replacement command. Legacy endpoint history in a `.versions` folder can be imported with `gitgrounded history import`.

## Before 1.0

GitGrounded is alpha. Minor releases may still change formats; each change is listed in the [changelog](/docs/changelog).
