The image is built from the repository `Dockerfile` (Python 3.12 slim with `git` and `gitgrounded[sign,mcp]`). Its entrypoint is `gitgrounded` and the working directory is `/work`.

```bash
docker build -t gitgrounded https://github.com/amareshhebbar/gitgrounded.git
```

Mount your repository at `/work` and pass keys as environment variables.

```bash
docker run --rm -v "$PWD:/work" -e ANTHROPIC_API_KEY gitgrounded run --base main --bundle
docker run --rm -v "$PWD:/work" gitgrounded verify evidence.ggb
docker run --rm -v "$PWD:/work" --env-file .env gitgrounded compare --prompt v1.txt --prompt v2.txt --model claude
```

<Note>
Git refuses to operate on a mounted repository owned by another user. If you see a "dubious ownership" error, run the container with `--user "$(id -u):$(id -g)"` or add `-e GIT_CONFIG_COUNT=1 -e GIT_CONFIG_KEY_0=safe.directory -e GIT_CONFIG_VALUE_0=/work`.
</Note>

## Local signing keys

Local Ed25519 keys are created under `$XDG_CONFIG_HOME/gitgrounded/keys/`. Mount a key and point `GITGROUNDED_SIGNING_KEY` at it so bundles from the container are signed with a stable identity.

```bash
docker run --rm -v "$PWD:/work" -v "$HOME/.config/gitgrounded:/keys:ro" -e GITGROUNDED_SIGNING_KEY=/keys/keys/ed25519.pem gitgrounded run --base main --bundle
```

## Certifier service

```bash
docker run -d -p 8765:8765 -v certifier:/work -e GITGROUNDED_CERTIFIER_TOKENS=secret -e ANTHROPIC_API_KEY gitgrounded certifier serve --host 0.0.0.0 --public-url https://certify.example.com
```

The certifier uses only the standard library HTTP server, so the base image runs it as is. Install `fpdf2` and `segno` in a derived image if you want PDF certificates. See [Independent certificates](/docs/certifier).
